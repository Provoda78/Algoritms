# Семинар 2. Реляционная алгебра на практике (radb)

## Цель

Освоить базовые операции реляционной алгебры с помощью интерпретатора `radb`.  
Вы научитесь загружать данные и выполнять запросы на языке реляционной алгебры.

Важно: SQL мы будем изучать позже. Сегодня только алгебра.

---

## Шаг 1. Установка radb

`radb` — это интерпретатор реляционной алгебры на Python.

Откройте терминал и выполните:

```bash
pip install radb
```

Проверьте установку:

```bash
python -c "import radb; print('✅ radb готов')"
```

Если видите `✅ radb готов` — всё в порядке.

---

## Шаг 2. Создание базы данных

`radb` работает поверх SQLite. Мы создадим базу данных и CSV-файлы с помощью Python.

В папке `setup/` есть два скрипта:

`init_db.py` — создаёт базу данных `employees.db` со всеми таблицами и данными.

Запустите:

```bash
cd setup
python init_db.py
cd ..
```

`create_csv.py` — экспортирует данные из базы в CSV-файлы (нужны для `radb`).

Запустите:

```bash
cd setup
python create_csv.py
cd ..
```

После этого в папке `data/` появятся файлы:

- `employees.csv`
- `departments.csv`
- `projects.csv`
- `works.csv`

---

## Шаг 3. Запуск radb и загрузка данных

Запустите `radb` из корневой папки проекта:

```bash
radb employees.db
```

Вы увидите приглашение:

```
ra>
```

Проверьте, что данные загружены:

```radb
\list;
```

Вы должны увидеть список отношений: `employees`, `departments`, `projects`, `works`.

---

## Шаг 4. Пример выполнения запроса

Выведем все данные из таблицы сотрудников:

```radb
employees;
```

Выведем только имена и зарплаты:

```radb
\project_{name, salary} employees;
```

Выведем сотрудников с зарплатой больше 100000:

```radb
\select_{salary > 100000} employees;
```

Объединим условия:

```radb
\select_{salary > 100000 and dept_id = 1} employees;
```

Обратите внимание: в конце каждой команды ставится `;`.

## Шаг 6. Оформление отчёта

Заполните шаблон `report_template.md`.

Для каждой задачи укажите:

1.  Код запроса на языке реляционной алгебры.
2.  Результат в виде таблицы (первые 5 строк или всё, если строк мало).
3.  Ответ на вопрос на понимание — своими словами, кратко.

Пример оформления:

### Задача 1

Код:

```radb
\project_{name} employees;
```

Результат:

| name            |
| --------------- |
| Anna Smirnova   |
| Boris Kuznetsov |
| ...             |

Ответ на вопрос на понимание:

> Команда `employees;` выведет всю таблицу со всеми атрибутами (id, name, salary, dept_id). Операция проекции оставляет только нужные столбцы — в данном случае `name`.
